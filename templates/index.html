POST /api/v1/auth/token/
Milestone 1 (JWT Login)

Authenticates user using email and password, returning access & refresh tokens.

// Request Body
{
  "email": "doctor@example.com",
  "password": "SecretPassword123"
}
// Response (200 OK)
{
  "access": "eyJhbGciOi...",
  "refresh": "eyJhbGciOi...",
  "user": { "id": 1, "email": "doctor@example.com" }
}
